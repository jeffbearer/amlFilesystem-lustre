# 2.17.0-RC1 Migration Analysis

## Executive Summary

**Goal:** Determine which patches from 2.15.7-client are still needed for 2.17.0-RC1

**Finding:** Of 33 patches in 2.15.7-client:
- **12 were kept** in 2.16.1-client (Microsoft-specific packaging/build changes)
- **21 were dropped** (mostly LU-* kernel compatibility fixes, likely upstreamed)

**For 2.17.0-RC1 Migration:** Of the 12 kept patches:
- ✅ **6 apply cleanly** (can cherry-pick directly)
- ⚠️ **8 have conflicts** (need manual resolution)
- ℹ️ **0 already upstream** (all still needed)

**File:** autoMakefile.am
**Analysis:** Context conflict in debian build targets. The patch adds oscode parameter to distinguish between Ubuntu versions (bionic/focal/jammy).
**Resolution Effort:** LOW - Likely just whitespace/context changes
**Still Needed:** YES - Critical for Ubuntu package naming

## Part 3: Patches Dropped (21 patches NOT in 2.16.1-client)

These were dropped when moving from 2.15.7 → 2.16.1, likely because they were upstreamed or became obsolete:

1. LU-15544 osd: Handle removal of EXT4_GET_BLOCKS_KEEP_SIZE
2. LU-15544 ldiskfs: SUSE 15 SP4 kernel 5.14.21 SUSE
3. LU-16364 llite: Move d_u.d_alias compat define
4. LU-16350 osd-ldiskfs: no_llseek removed, dquot_transfer
5. LU-14918 osd: don't declare similar ldiskfs writes twice
6. LU-16328 llite: migrate_folio, vfs_setxattr
7. LU-16205 sec: reserve flag for fid2path for encrypted files
8. LU-1904 idl: add checks for OBD_CONNECT flags
9. LU-16619 build: Ubuntu jammy 5.19 client support
10. LU-10391 lnet: only use PUBLIC IP6 addresses for connections
11. LU-16327 llite: read_folio, release_folio, filler_t
12. LU-13485 build: fscrypt checks can be run in parallel
13. LU-13485 kernel: Parallel core configure tests
14. LU-15058 libcfs: introduce genradix support
15. LU-15420 sec: handle simple fscrypt changes for 5.15 kernels
16. LU-16205 sec: fid2path for encrypted files
17. LU-16415 quota: enforce project quota for root
18. LU-15544 osd-ldiskfs: Update bio_set_dev and BIO_MAX_VECS
19. Fix LNET so it doesn't go down often in AKS deployments
20. Revert addition linux-headers-azure in debian package requirements
21. Add linux-headers-azure and linux-image-azure in debian packages

**Analysis:** Most are LU-* patches addressing kernel API changes in 5.14-5.19 kernels. Since 2.17.0 targets newer kernels, these fixes are either:
- Already in upstream 2.17.0
- Superseded by upstream solutions
- No longer relevant

**Notable Exception:** "Fix LNET so it doesn't go down often in AKS deployments" - This is a Microsoft-specific fix that may need investigation. If AKS stability is still an issue, this patch should be examined.
